# Personalized Fitness Class Booking Platform

MERN Stack project foundation for HCL/GUVI submission.

## Structure
- client/ - React + Vite frontend for Netlify
- server/ - Node.js + Express backend for Render

## Netlify
Base directory: client
Build command: npm run build
Publish directory: dist

## Render
Root directory: server
Build command: npm install
Start command: npm start

Backend environment variables: PORT, MONGODB_URI, JWT_SECRET, CLIENT_URL.

This package is the working foundation represented in the supplied Work File. The Work File states that the complete authentication, role dashboards, CRUD and booking features are intended for further completion.
